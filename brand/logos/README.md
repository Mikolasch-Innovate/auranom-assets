# AURANOM logos

Source of truth for the AURANOM logo files. The SVGs come from `auranom-master-app/Concept/logos/`
(Brand Design Concept v2); the PNGs are rendered from them for places that cannot show SVG (e-mail).

| File | Use |
|---|---|
| `auranom-logo-white.svg` | full logo (mark + wordmark) on dark surfaces |
| `auranom-logo-blue.svg` | full logo, brand colors (#162272 + #17B5A3), on light surfaces |
| `auranom-logo-black.svg` | full logo on light surfaces, monochrome |
| `png/auranom-logo-{variant}@2x.png` | full logo, 680 × 212 px (shown at 340 × 106), transparent |
| `png/auranom-logo-{variant}-trimmed@2x.png` | same render, empty margin of the SVG canvas cut off (586 × 161 px), for tight layouts such as e-mail headers |

## Rules (Brand Design Concept v2)

- Full logo: minimum width 80 px.
- Clear space: at least 1 × logo height on all sides.
- Do not stretch, recolor, crop, or add shadows or filters. Use only the white, blue or black variants.
- Do not place the logo on backgrounds with less than 3:1 contrast.

## Users

- AURANOM Review Pipeline (SPECTRA) HTML report mail: `png/auranom-logo-white-trimmed@2x.png`, embedded inline at 100 px width.
